Admoniciones

Los 12 tipos de Zensical adaptados a la paleta y a los íconos del brand-book. Se escriben igual en Markdown: !!! tipo "Título".

Nota

Información complementaria al texto.

!!! note

Resumen

Síntesis de una sección.

!!! abstract

Información

Contexto o dato adicional.

!!! info

Consejo

Una recomendación práctica para el facilitador.

!!! tip

Éxito

Resultado esperado o tarea cumplida.

!!! success

Pregunta

Una pregunta para reflexionar.

!!! question

Advertencia

Algo que conviene revisar antes de avanzar.

!!! warning

Fallo

Un resultado que no es el esperado.

!!! failure

Peligro

Un error que rompe la lección.

!!! danger

Error

Un fallo conocido del código.

!!! bug

Ejemplo

Un caso concreto para ilustrar.

!!! example

Swirl Development Team

“Si alguien puede escribir un script de R, puede crear una lección.”

!!! quote
